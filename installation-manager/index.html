3. Information, purpose, storage, and contact

Workspace records and app-local browser state are stored on this Windows computer or in the data folder you configure. The Manager stores configuration and its encrypted first-install consent record under your Windows user profile; verified backup copies are stored locally under the Manager's backup folder. Backups may contain the same business or personal information as the source data, are not a substitute for an independent backup, and are not automatically encrypted by the Manager. 4. Network requests and other providers

Before a first-time installation, no release request is made until you choose “Yes, I agree”. After that, the Manager requests public release metadata from GitHub and downloads the selected installer from github.com or its GitHub-hosted download domains. GitHub receives ordinary connection data such as your IP address and request headers. The Manager does not upload your workspace records as part of this update check. Separately, Desktop sign-in, shared workspace features, and integrations you configure can send the information needed for those functions to Firebase or the selected provider. Those services have their own terms, privacy notices, processing locations, retention practices, and availability. Review each provider's terms before connecting it.

5. Compatibility and required software

The Manager identifies the Windows product type, edition, build, and architecture. It offers Desktop and Cylinder Server in the product picker, but enforces each product's compatibility rules: Desktop install and update are limited to Windows 10/11 Home, Pro, and Enterprise workstations; Cylinder Server install and update require Windows Server/IoT build 17763 or later. An already-installed product can remain selected for removal on another edition if its registration and uninstaller can be verified. Windows Education and other editions outside those groups are not currently declared supported. Both products currently require native x64 hardware, at least 2 logical processors and 4 GB of physical memory, Windows PowerShell 5.1 with required system inspection/signature commands, package integrity, and enough free space for the verified download, local backup, staged data restore, and installation reserve. The Desktop package bundles Electron, Chromium, and Node.js, so it requires no separate .NET, Visual C++ runtime, WebView2, browser, plug-in, or extension. No external prerequisite is declared for the Server package either. The Manager installs no extra component; if a required check fails or a package later declares a component without an approved, verifiable installer, installation stops with a reason. Native ARM64 is not supported by these x64 releases. Edition detection identifies the target but does not certify every Windows Server/IoT servicing configuration.

6. Installation, Windows changes, updates, and removal

Setup can request administrator approval, install the selected program machine-wide, create Start menu and desktop shortcuts, and register it with Windows for removal. Launch-at-sign-in is optional and changes your Windows user startup setting only when you enable it. The Manager downloads the selected product's release installer over HTTPS and checks release version, product-specific filename, file size, SHA-512, and Authenticode according to this build's policy. A hash confirms a match with release metadata; it does not independently identify the publisher. On replacement, the Manager backs up the selected product's data folder, removes that product's existing program, installs the matching release, and verifies the result. Desktop and Cylinder Server have separate installation and data folders; data is not copied between products. If setup fails after removal, you may need to reinstall; the verified data backup remains available. Uninstall keeps local data by default. Optional data removal requires a separate choice and typed confirmation; the Manager's backup remains until you remove it separately.

7. Backup, recovery, and security limits

SHA-256/SHA-512 checks detect file differences; they do not guarantee data correctness, confidentiality, recoverability, or publisher identity. The Manager compares/restores the configured data folder during replacement, but a power loss, disk failure, malware, filesystem error, inaccessible custom folder, or files stored elsewhere can affect results. Keep separate backups of important records and documents outside OverHead. The Manager's unsigned local build can be replaced or patched by someone with sufficient access to the computer. No security control eliminates all risk. Review exports and support bundles before sharing them.
