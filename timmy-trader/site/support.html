Support and troubleshooting

Use these checks to identify installation, account-configuration, data, or automation issues before contacting support.

Installation

Verify the package checksum, confirm the installed version, and note any package-manager or launch errors. The current release is listed on the Download page.

Account configuration

Verify the Webull profile locally, run Account Check, and confirm the account identity and buying-power snapshot before using an order preview.

Automation readiness

Review the selected target, operating mode, market-data timestamp, account status, risk blockers, and unresolved order notices in Timmy's Automation and Health workspaces.

When reporting an issue, include the Timmy version, the relevant workspace, what you expected, and the exact message shown. Do not include broker credentials, passwords, account IDs, or private trading records.
