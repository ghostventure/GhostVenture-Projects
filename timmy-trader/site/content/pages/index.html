The workflow

From movement to a considered action.

A watchlist candidate is only a starting point. Each stage applies its own criteria before activity can reach an execution lane.

01 / DISCOVER

Find notable movement

Rotating universe scans rank daily price movement against configurable percentage thresholds, then save notable symbols for review.

02 / QUALIFY

Apply strategy and risk

Plans check configured quantity, notional, account cash, strategy readiness, and other limits before an order is eligible.

03 / EXECUTE

Track the outcome

Paper and Simulation have separate records. Live order routing requires supported broker access and the configured safety gates.
