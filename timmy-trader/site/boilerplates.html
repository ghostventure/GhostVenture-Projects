Configuration examples

These downloads are plain-text examples for experienced operators. They are not presets and Timmy does not import them. Most users should configure their broker in the app’s Setup workspace and follow the Webull setup guide.

A saved local Webull profile can override broker-profile settings from environment files. Never put real credentials in these examples. Review each variable against the installed version before changing a local environment.
