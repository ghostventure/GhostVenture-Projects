# OverHead 0.3.24 — local GUI and workflow improvements

This note records the 0.3.24 changes in the current checkout. It describes local source/build contents only; it does not confirm a GitHub release, Firebase deployment, or installation on a user's computer.

## Workspace navigation and helper

- The app shell has a consistent visual treatment, clearer shared surfaces, more visible keyboard focus, and responsive layouts for narrower windows.
- The workspace directory supports search, collections, reordering, hiding entries, display density and target-size preferences, and exporting/importing its navigation preferences. These preferences are device-local. Hiding a directory entry does not change a person's permissions.
- The Workspace helper groups current-work summaries, completeness checks, recent activity, guidance, privacy acknowledgements, external-service permission links, and a support-bundle review flow. Fictional workflow previews do not create records. Support bundles are created locally only after a permitted user confirms the reviewed contents.

## Overview operations checks

The Overview dashboard includes a Work quality and data checks panel:

- **My work today** summarizes open tasks due today and today's appointments from records currently loaded.
- **Possible duplicate customers** flags exact email matches, or exact name matches when an email is absent. Review candidates before using the existing merge workflow.
- **Bulk task status** displays the selected tasks and proposed status changes for confirmation before applying them.
- **CSV row check** previews header, row-width, repeated-row, and selected required-field issues. It does not import records.
- **Appointment conflicts** highlights overlapping appointments; a missing duration is treated as 60 minutes.
- **Customer data completeness** identifies loaded customer records missing a name, email, phone, or service area. It does not fill fields.
- **Local backup status** reads the protected local backup inventory and allows Owners and Bookkeepers to create a local backup.
- **Operations export history** lists exports created by this panel on this device. The CSV includes current tasks, appointments, and customers; the history does not cover other export tools.
- **Existing draft recovery** points users back to supported forms that save drafts locally.

These cards are review aids. They do not establish cross-device synchronization, guarantee a complete backup, or automatically merge or edit customer records.
