# OverHead 0.3.17

OverHead 0.3.17 completes the locally deliverable work from the 400-item feature wave. It adds role-aware task and project workflows, customer and sales workspaces, reporting/search controls, document content search and safe PDF/ZIP workflows, local audio-note capture, planned team utilization, and opt-in trial/sync reminders, consented site labels, local calendar-file exchange, backend-enforced conditional approvals, configurable IDs for supported new records, and Owner-run local field-update rules.

The audit counts **272 implemented**, **82 already present**, **0 partial**, and **46 blocked by concrete prerequisites**. The remaining blockers require hosted payment, booking, calendar, file-sharing, signature, webhook, or delivery services; safe workspace/customer identity transactions; account security infrastructure; or native iOS build/signing and device features. Each is listed with its prerequisite in the range audits linked from [the 400-item audit](feature-wave-400.md).

The public user guide documents the new workflows and their limits. Local features do not imply provider credentials, background delivery, public integrations, or native iOS capabilities that are not configured.
