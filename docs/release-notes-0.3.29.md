# OverHead 0.3.29

This update extends the 0.3.28 local workflow wave with a responsive Field Companion for appointment agenda, checklists, and visit notes. Photo and audio capture require explicit consent and remain user-controlled local downloads; media is not uploaded automatically.

The Integrations workspace now includes optional provider preferences. All provider groups default off, require explicit opt-in, and preserve local workflows when disabled. These preferences are not live provider connections; authenticated adapters and provider setup remain separate.
