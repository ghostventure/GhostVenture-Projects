# OverHead 0.3.16

This feature wave adds role-aware workspaces for dashboard planning, tasks, projects, customers, sales, finance, people operations, scheduling, document control, collaboration, reporting, automation, integrations, search, field work, support operations, and security review. Local records use the encrypted OverHead store and are limited by the signed-in staff role.

The full 400-item inventory, implementation evidence, and provider/platform prerequisites are documented in [feature-wave-400.md](feature-wave-400.md). Some ideas remain partial or blocked; the audits distinguish those from completed and pre-existing behavior. External connectors do not collect provider passwords or tokens through generic workspace records.

The updated desktop installer, portable ZIP, guide, checksums, updater manifest, GitHub publication, and website deployment are pending the integrated compile and packaged verification gates.
