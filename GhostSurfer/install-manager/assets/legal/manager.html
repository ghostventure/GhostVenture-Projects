Install, update, uninstall, and downloads

GS Install Manager installs or updates Ghost Surfer from the bundled local payload or a ZIP/folder you select. Updates replace program files in %LOCALAPPDATA%\Programs\Ghost Surfer after a running copy closes; they do not force-close Ghost Surfer. Uninstall removes only that program folder and Ghost Surfer shortcuts. The browser profile at %LOCALAPPDATA%\GhostSurferLocal\Ghost Surfer is preserved.

If the required Microsoft Visual C++ runtime is missing or outdated, the manager asks for consent, downloads the official redistributable from Microsoft, verifies its signature and file hash, and uses the normal Windows UAC prompt to install it. The manager itself currently uses a local Ghost Surfer package and does not contact GitHub for that package. When a GitHub update checker is enabled in Ghost Surfer, update checks/downloads contact GitHub. Network providers may process ordinary connection metadata for those requests.

The manager has no analytics or usage-reporting code. This statement describes the manager; it does not describe data collection by websites you visit or third-party Windows services.
