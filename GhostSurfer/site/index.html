Ghost Guard

Privacy controls you do not need a tech degree to use.

Ghost Surfer does not promise magic invisibility. It gives you clear, practical privacy controls: the Windows browser offers per-site cookie decisions, tracker blocks, and permission controls. The native Mac preview uses Apple's WebKit protections and adds private tabs, tracker blocking, and HTTPS upgrades. It does not yet include every Windows privacy control.

Interface

A browser tuned for each desktop.

The Windows edition groups privacy status, cookie decisions, alerts, downloads, bookmarks, history, themes, and cleanup in its control center. The Mac preview uses a native window with a tab and library sidebar, private tabs, and a central Ghost Control panel.

  • Consistent control sizing, spacing, focus states, and a simplified address row
  • Windows: one privacy notice panel for cookie consent and grouped alerts
  • Windows: per-site consent or global first-party cookie rules
  • Mac: WebKit browser with private tabs, bookmarks, and history
  • Persistent page zoom from 80% to 150% for more comfortable reading
  • Speed Mode and optional image blocking for heavier pages
  • Familiar keyboard shortcuts for tabs, address focus, reload, and stop loading
  • Confirmed cleanup for cookies, cache, history, saved cookie choices, and alerts

Install

Choose your platform.

Windows has a per-user setup package. Mac has a universal installer for Apple silicon and Intel, currently offered as an unsigned preview.

  1. Download and extractDownload the current setup ZIP and choose Extract All.
  2. Run GS Install ManagerOpen the included manager and follow its setup flow. It validates the staged Qt WebEngine runtime before replacing program files.
  3. Mac: open the packageOpen Ghost-Surfer-macOS-0.1.0.pkg and follow Installer. It places Ghost Surfer in Applications. Requires macOS 14 or later.
  4. Mac: approve the previewThis package is not signed or notarized. Gatekeeper may require manual approval before Installer and the app can open.

Mac Preview · Version 0.1.0

Ghost-Surfer-macOS-0.1.0.pkg

Universal installer for Apple silicon and Intel Macs running macOS 14 or later. Installs Ghost Surfer.app into Applications. Includes private tabs, WebKit tracking protections, known tracker blocking, HTTPS upgrades, bookmarks, and history. The Mac preview uses WebKit cookie handling and does not include the Windows app's per-site cookie approval or local Tor routing.

Unsigned preview: this package is not signed or notarized. Gatekeeper will require manual approval, and first-run steps may vary with your macOS settings. Only install it if you trust the source.
