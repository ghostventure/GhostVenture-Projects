Browser features

Privacy, compatibility, recovery, and cleanup in one feature list.

Ghost Surfer does not promise anonymity. It gives you understandable controls for cookies, site permissions, page compatibility, saved data, and updates, grouped in Ghost Control and the page context menu.

Stops Location RequestsWebsites are blocked from asking the browser for your exact location by default.
One Consent PanelCookie choices and privacy notices share one bottom panel. Allow or block a site, dismiss informational notices, or choose a global first-party cookie policy in Ghost Control.
Cookie Decisions ManagerReview allowed and denied sites, then forget one choice or reset them all from Ghost Control.
Grouped Privacy AlertsTracker and blocked-permission notices use the same panel and are grouped to avoid a chain of separate pop-ups.
Personal Data Request ReviewPause common form submissions and choose which detected personal fields to send. Optional domain-registration checks provide risk signals; they do not certify a business.
Optional Personal Data VaultStore contact details and site logins in a separate Windows-encrypted module. Credit cards are not supported.
Optional Tor SupportIf you already use Tor on your computer, Ghost Surfer can use that route when it is available.
Locks Down Nosy PermissionsCamera, microphone, notifications, screen sharing, clipboard, and local font access are blocked by default.
Future Console LookA sharper 2033-style privacy console with neon edge lighting, dark glass panels, and 12 theme-aware accent colors.
Tamper WarningIf local browser settings are changed outside the app, Ghost Surfer warns you before you keep browsing.
DuckDuckGo HomeDuckDuckGo is the default home page; the address-bar search provider remains a separate preference.
Temporary Site ControlsAllow JavaScript or images for one site for the current browser session, with an on-screen indicator.
Safer RecoveryAfter an unexpected close, select which tabs to restore; URLs with query or fragment data start unchecked.
Profile ResetReset settings and browsing records after Ghost Surfer makes a dated backup; bookmarks can be preserved.
Accessible ControlsResize interface text, increase contrast, reduce browser scroll motion, and follow a visible keyboard focus indicator.
Download ManagementTrack progress and source, open or show a file, cancel active transfers, or confirm deletion of a completed file and record.
GitHub UpdatesCheck compatible Ghost Surfer releases, review release notes, verify the package, and approve installation.
HTTPS PreferredGhost Surfer upgrades plain HTTP pages to HTTPS when the secure version is available.

Interface

Not another Chrome clone.

Ghost Surfer uses consistent spacing, rounded controls, readable labels, and a cleaner address row. Privacy status, cookie decisions, alerts, downloads, bookmarks, history, themes, and cleanup stay close by in the control center.

  • Searchable Ghost Control groups related settings and tools by topic
  • Quick Access (Ctrl+K) finds actions, tabs, bookmarks, and recent pages
  • Address, tabs, and loading status expose screen-reader names
  • Keyboard shortcuts include Ctrl+L, Ctrl+T, Ctrl+W, Ctrl+F, and F1
  • Page zoom and interface text sizing are separate controls
  • Download, cookie, history, cache, and profile actions stay grouped in Ghost Control

Install

Download, extract, install.

The Windows package includes Ghost Surfer and GS Install Manager. The manager checks this computer's requirements before installing; it asks first if a required Microsoft component needs to be added.

  1. Download and extractDownload the current setup ZIP and choose Extract All.
  2. Run GS Install ManagerIn the extracted folder, open GS Install Manager.exe and choose Install. The manager checks the app package, Windows version, architecture, available disk space, and Visual C++ runtime.
  3. Review any requirement promptIf a required Visual C++ component is missing or outdated, the manager explains the official Microsoft download and asks for your consent before installing it.
