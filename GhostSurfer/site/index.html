Ghost Guard

Practical privacy, without the fuss.

Ghost Surfer gives you straightforward ways to manage browser activity across Windows, Linux, and Mac. Windows and Linux include tracker filtering and grouped alerts; Mac includes WebKit tracking protection, private tabs, and HTTPS upgrades. Each version has its own feature set, and none makes you anonymous.

A guided installation

Your device gets the right manager.

The site detects your platform and routes you to its installation manager. The manager checks your system, selects the newest compatible Ghost Surfer release, verifies the download, and starts installation. You can also choose a platform below.

Current Linux catalog · Version 0.2.6

Ghost Surfer for Linux

For 64-bit x86 Linux. The manager identifies your distribution and version, checks its compatibility group and glibc, then selects and verifies a suitable release before starting the per-user installer. Similar derivatives can share one build when their compatibility is verified. The current tested target is Kali Linux with glibc 2.43.

Linux compatibility and feature details

Built and smoke-checked on Kali Linux with glibc 2.43; older distributions are not yet verified. Alpine/musl, ARM, and 32-bit systems are not covered by this package. Personal Data Vault is not available on Linux.

Current Mac catalog · Version 0.2.3

Ghost Surfer for Mac

For Apple silicon and Intel Macs running macOS 14 or later. Download the Mac installation manager to start setup. The manager is Intel x86_64; Apple silicon may need Rosetta 2 to open it. It selects the compatible Mac release, verifies it, then hands off to the installer.

Mac app details and installation help

The Mac installation manager is an Intel x86_64 app. Apple silicon Macs can run it through Rosetta 2, which macOS may ask you to install. Mac uses WebKit cookie handling; per-site cookie controls and optional local Tor routing are currently available in the Windows and Linux apps. The manager installs the verified app archive for your user. The app does not have an Apple Developer ID signature, so macOS may ask you to approve it in Privacy & Security. Automatic update checks are optional and require your consent; update archives are signed. Existing version 0.1.0 installs need a one-time reinstall to enable in-app updates.

Current Windows catalog · Version 0.2.6

Ghost Surfer for Windows

For x64 PCs running Windows 10 version 1809 or newer, or Windows 11. The Windows manager checks the OS build and required runtime, then selects and verifies a compatible browser release before installation.

Package, updater, and security details

The Windows manager ZIP is about 41.7 MiB and contains only GS Install Manager.exe. It gets the browser setup separately. Windows binaries are not Authenticode-signed.
