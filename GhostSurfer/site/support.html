Need help?

Platform-specific install steps and recovery pointers for the current downloads.

Windows

  1. Download the current Windows ZIP and choose Extract All.
  2. Keep the extracted files together, then open GS Install Manager and follow its prompts.
  3. The manager checks the staged Qt WebEngine runtime before replacing program files.

Linux

  1. Download the x86_64 Linux archive and extract it.
  2. Open the extracted folder and run ./install-linux.sh. It installs for your account and does not need sudo.
  3. Launch Ghost Surfer from your applications menu. Compatibility with older distributions is not yet verified.

Mac

  1. Download version 0.2.0 and follow the installer. It requires macOS 14 or later.
  2. If macOS asks for approval, use the Open Anyway steps in the download card. Version 0.1.0 installs need this one-time reinstall before in-app updates work.

Download verification

The download cards link to current checksums. If a checksum does not match, do not open the file; download it again from the listed source.
