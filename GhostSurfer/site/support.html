Support

Need help?

Platform-specific install steps and recovery pointers for the current downloads.

Windows

  1. Download the Windows Installation Manager ZIP and extract it.
  2. Run GS Install Manager.exe. The manager checks your system, downloads the browser package, verifies it, and guides installation.
  3. The manager ZIP contains the manager only. The browser package is a separate download. Windows binaries are not Authenticode-signed.

Linux

  1. Download the Linux Installation Manager and extract it.
  2. Run ./ghost-surfer-manager as your regular user; no sudo is required. The manager detects the Linux distribution, checks compatibility, and selects the browser release.
  3. Kali Linux with glibc 2.43 is the verified target. Other glibc distributions show a compatibility warning; Alpine/musl, ARM, and 32-bit systems are unsupported.

Mac

  1. Download and open the Mac Installation Manager ZIP. macOS will expand the ZIP; open the included app. The current Mac app is version 0.2.3 and requires macOS 14 or later.
  2. The manager is an Intel x86_64 app. Apple silicon Macs may need Rosetta 2 to open it. If macOS asks for approval, use the Open Anyway steps in the download card.

Download verification

The download cards link to current checksums. If a checksum does not match, do not open the file; download it again from the listed source.
