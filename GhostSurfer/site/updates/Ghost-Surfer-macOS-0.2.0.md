## Ghost Surfer 0.2.0

- Adds opt-in automatic update checks and background downloads.
- Verifies signed update feeds and update archives before use.
- Adds a manual **Check for Updates…** command and a recovery prompt if installation fails.
- Adds first-run update consent with links to the Privacy Policy and Terms.
- Existing 0.1.0 installations need a one-time manual reinstall before in-app updates are available.
