Accessibility statement

Accessible by design.

Ghost Surfer aims to keep the public website usable with keyboard navigation, readable contrast, semantic structure, and responsive layouts.

Accessibility is an ongoing practice. Report barriers through the Support page so they can be reviewed and fixed.

Website Measures

  • Semantic HTML landmarks, headings, lists, and links.
  • High-contrast dark color scheme with visible text.
  • Responsive layout for desktop and mobile screens.
  • Text alternatives for brand imagery where needed.
  • No autoplaying audio or video on the current site.

Known Limits

Accessibility behavior in the desktop apps depends on the selected operating system and browser engine. Third-party websites loaded inside Ghost Surfer control their own accessibility; the site cannot guarantee the accessibility of external sites.

Feedback

If you encounter an accessibility issue, email solidartentertainment@gmail.com and include the page URL, assistive technology used if applicable, browser or device, and a short description of the barrier.
