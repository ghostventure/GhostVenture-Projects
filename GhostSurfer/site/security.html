Security posture

Security and Privacy Limits

Ghost Surfer includes practical protections, but no browser can promise absolute privacy or anonymity.

Built-In Protections

  • On Windows and Linux, sensitive site permissions are denied by default and known tracker hosts are filtered.
  • On Windows and Linux, cookie choices and local Tor routing are available as described on the download page; Tor itself is not included.

macOS Update Integrity

Ghost Surfer for macOS checks updates over HTTPS. Sparkle verifies the signed update feed, release notes, and update archive before extraction. The release build also verifies the app's code signature, universal architecture, required Sparkle security settings, and the feed and archive signatures before publication. The public verification key is embedded in the app; the matching private key stays in the release maintainer's Keychain.

The initial macOS installer package does not have an Apple Developer ID signature. Its published SHA-256 helps detect an incomplete or altered download when compared with the value on this official site. The app bundle is ad-hoc signed; this is not an Apple developer identity.

Important Limits

Ghost Surfer does not hide your IP address by itself. If Tor, VPN, or another trusted network layer is not active, websites and network providers may still infer approximate location from network data.

Security Claims

Security and privacy descriptions on this site describe current built-in controls. They are not a promise that Ghost Surfer prevents every tracking method, attack, breach, or identification technique.

Verifying Downloads

Always compare the published SHA-256 values before running a downloaded build. Do not run files from unofficial mirrors unless you trust the source and verify the checksum.

Reporting Issues

Report suspected security issues through the Support page. Include app version, operating system and version, reproduction steps, and whether Tor or a VPN was active, if relevant.
