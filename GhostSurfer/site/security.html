Security posture

Security and Privacy Limits

Ghost Surfer includes practical protections, but no browser can promise absolute privacy or anonymity.

Built-In Protections

  • Geolocation, camera, microphone, notifications, desktop capture, clipboard access, and local font access are denied by default.
  • Third-party cookies are blocked by default.
  • Known tracker hosts are filtered by the request interceptor.
  • DuckDuckGo is the default home page. Startpage remains the default address-bar search provider.
  • Local Tor SOCKS routing is used when a compatible local Tor service is detected at startup.
  • The browser's IP tripwire reports recognized public-IP lookup requests without blocking them.
  • Privacy settings reduce some tracking but do not make direct network connections anonymous.

Important Limits

Ghost Surfer does not hide your IP address by itself. If Tor, VPN, or another trusted network layer is not active, websites and network providers may still infer approximate location from network data.

Security Claims

Security and privacy descriptions on this site describe current built-in controls. They are not a promise that Ghost Surfer prevents every tracking method, attack, breach, or identification technique.

Verifying Downloads

Always compare the published SHA-256 values before running a downloaded build. Do not run files from unofficial mirrors unless you trust the source and verify the checksum.

Reporting Issues

Report suspected security issues through the Support page. Include app version, Windows version, reproduction steps, and whether Tor/VPN was active.
