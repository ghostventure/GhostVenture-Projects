Ghost Surfer help

Frequently asked questions

Straightforward answers about privacy, platform differences, updates, and downloads.

Features and requirements differ by platform. The Downloads page lists the current versions, package details, and checksums.

Privacy and browsing

What is Ghost Surfer?

Ghost Surfer is a privacy-focused desktop browser. The Windows and Linux editions use Qt WebEngine; the Mac edition is a separate native WebKit app. Each platform's current features are listed on the Downloads page.

Does Ghost Surfer make me anonymous?

No. Ghost Surfer adds privacy controls, but websites and network providers can still see the network connection used to reach them. Windows and Linux can use a compatible Tor service already running on your computer; Tor is not included. The Mac app does not include Tor routing.

What does Ghost Guard block?

On Windows and Linux, Ghost Guard filters a built-in list of known tracker hosts and denies sensitive website permissions by default. Cookie controls let you choose how first-party cookies are handled. These protections do not catch every tracker or prevent every form of identification.

Does private browsing hide my activity?

The Mac app includes private tabs that use a temporary WebKit data store and do not add pages to browsing history. Websites and network providers may still observe activity. The Windows and Linux 0.2.6 releases do not advertise a separate private-tab mode; clearing cookies, cache, and history is available in their browser controls.

Is my browsing data sent to Ghost Surfer?

The website has no account system or analytics. Browser profiles are stored locally. Update checks can contact third-party release services: Linux checks GitHub at startup by default, while Mac checks begin only if you opt in to Sparkle. Those requests include ordinary connection metadata such as your IP address, but do not send browsing history, bookmarks, or page contents. See the Privacy Policy for details.

Does Ghost Surfer sync bookmarks or history between devices?

No. Ghost Surfer does not provide cloud sync. Browser data is kept in the local profile on each device.

Platforms and features

What is different between Windows, Linux, and Mac?

Windows and Linux share Ghost Control, cookie choices, tracker filtering, permission restrictions, and the main tab and library tools. The Mac app uses Apple's WebKit and includes private tabs, bookmarks, history, tracker protections, and HTTPS upgrades; it does not include the desktop apps' per-site cookie controls or Tor routing. Check each download card for the exact scope.

Which Mac computers can run Ghost Surfer?

The Mac app supports Apple silicon and Intel Macs running macOS 14 or later. Its current installation manager is Intel x86_64; Apple silicon Macs may need Rosetta 2 to open the manager. The app installs in Applications.

Which Linux computers can run this release?

The Linux manager supports x86_64 systems using glibc. Kali Linux with glibc 2.43 is the verified target. Other glibc distributions show an unverified compatibility warning; ARM, 32-bit Linux, and musl-based systems such as Alpine are not supported.

Does Linux installation need sudo?

No. Download and extract the Linux Installation Manager, then run ./ghost-surfer-manager as your regular user. It detects your distribution and installs for your account. See Support for details.

Does Ghost Surfer include a password manager?

The optional Personal Data Vault is available only in the Windows build and uses Windows account encryption. It can store selected personal information, including usernames and passwords. It is not available in the Linux or Mac builds.

Can I install browser extensions?

The Windows and Linux builds support optional local extension imports. Imported extensions start disabled until you review and enable them in Ghost Control. This does not provide Chrome Web Store compatibility. The Mac app does not include the desktop extensions feature.

Downloads, updates, and support

How does the site choose an installation manager?

Your browser identifies its desktop platform and available architecture hints. The site checks the shared manager catalog and offers a matching published download. The Linux manager then checks the exact distribution, version, architecture, and glibc on your computer before selecting a browser release. The website does not identify your Linux distribution.

Does the manager download include the browser?

No. The Windows, Linux, and Mac manager downloads contain the manager only. After launch, the manager checks compatibility and gets the matching browser package separately. The Windows manager ZIP includes GS Install Manager.exe without the browser payload.

Are the current downloads free?

Yes. The current Windows, Linux, and Mac downloads are offered free of charge. The website does not require an account or collect payment.

How do updates work?

Use the website's platform manager to select and download the current Windows or Linux release. Inside the Linux app, update checks run at startup by default; you can turn them off in settings, and downloading and applying an update require confirmation. On Mac, Sparkle checks and background downloads start only if you choose “Agree and Enable.”

Why does macOS warn me about the installer?

The current Mac installer package does not have an Apple Developer ID signature. If macOS blocks it, follow the “Open Anyway” instructions on the Mac download card. The package's SHA-256 is listed there too. Only install it if you trust the official source.

How do I verify a download?

Open the SHA256SUMS.txt file and compare the hash for your exact filename with the SHA-256 calculated on your device. If the values differ, do not run the file; download it again from the official link.

Where can I get help or report a security issue?

Visit the Support page or email solidartentertainment@gmail.com. For a security report, include the app version, operating system, and steps to reproduce the issue. Do not email passwords or private files.
