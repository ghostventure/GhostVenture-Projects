Third-party notices

Components and service references.

Ghost Surfer uses and references third-party technologies. Their terms and licenses remain separate from Ghost Surfer's own policies.

Application Runtime

The Windows package is built with Python and PySide6/QtWebEngine and includes runtime files needed for the app to run. QtWebEngine includes Chromium-based browser technology. Third-party components remain subject to their own license terms.

Referenced Services

  • DuckDuckGo is the default home page. Startpage remains the default address-bar search provider unless the user changes it.
  • Tor routing is attempted only when a local Tor SOCKS service is already running and reachable.
  • Firebase Hosting is used to serve the public website and download files.

No Bundled Tor Service

The current Ghost Surfer package does not install or operate the Tor network service for the user. It detects a local SOCKS endpoint when available.

License Review

Before commercial distribution, complete a formal third-party license review and include any required bundled notices for all runtime files shipped in the ZIP.
