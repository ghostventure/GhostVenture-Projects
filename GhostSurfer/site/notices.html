Third-party notices

Components and service references.

Ghost Surfer uses and references third-party technologies. Their terms and licenses remain separate from Ghost Surfer's own policies.

Application Runtime

The Windows package is built with Python and PySide6/QtWebEngine and includes runtime files needed for the app to run. QtWebEngine includes Chromium-based browser technology. Third-party components remain subject to their own license terms.

Mac Browser and Updates

The Mac app uses Apple WebKit for browser pages and Sparkle for optional app updates. Those components remain subject to their own notices and terms.

Referenced Services

  • Startpage is used as the default home/search destination.
  • Windows and Linux can attempt Tor routing when a compatible local Tor SOCKS service is running and reachable.
  • GitHub's release API is used for Linux startup update checks.
  • Firebase Hosting serves the public website and download files.

No Bundled Tor Service

Ghost Surfer does not bundle or operate the Tor network service. Windows and Linux can use a compatible local SOCKS endpoint when available.

License Review

Before commercial distribution, complete a formal third-party license review and include required notices for the runtime files in each distributed package.
