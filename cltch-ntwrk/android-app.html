Install

Open CLTCH.NTWRK on Android

A native Android package is not currently available. You can open CLTCH.NTWRK in your browser and add a home-screen shortcut for app-like access.

Use the browser version
  1. Open CLTCH.NTWRK in Chrome on your Android device.
  2. Open the browser menu and choose Install app, or choose Add to Home screen if that is the option shown.
  3. Launch CLTCH.NTWRK from the new home-screen icon. An internet connection is required.

The native Android package download is unavailable. This browser shortcut is not an APK and does not provide offline use.
