OverHead Suite for Mac 0.1.4

Requirements: Intel Mac (x86_64) running macOS 14 or later.

Install:
1. Open OverHead-Mac-0.1.4.zip in Finder.
2. Drag OverHead.app to Applications.
3. If macOS blocks the unsigned app, open System Settings > Privacy & Security and choose Open Anyway for OverHead. Only do this if you downloaded the package from the official OverHead website.

This release is not signed or notarized with an Apple Developer ID. It is an Intel-only build. Windows and Mac operational records are stored separately and do not sync automatically. The app checks for updates, but does not install them silently. Version 0.1.4 checks existing workspace records for similar business information before signup, clarifies prior-account reuse, and requires confirmation before creating a separate workspace. It also shows the no-card trial; paid checkout and paid cancellation are not available.

SHA-256 is published in SHA256SUMS.txt.
