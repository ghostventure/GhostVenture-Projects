OverHead for Mac 0.1.0 (Preview)

Requirements: Intel Mac (x86_64) running macOS 14 or later.

Install:
1. Open OverHead-Mac-0.1.0.zip in Finder.
2. Drag OverHead.app to Applications.
3. If macOS blocks the unsigned preview, open System Settings > Privacy & Security and choose Open Anyway for OverHead. Only do this if you downloaded the package from the official OverHead website.

This preview is not signed or notarized with an Apple Developer ID. It is an Intel-only build. Windows and Mac operational records are stored separately and do not sync automatically. The app checks for updates, but does not install them silently.

SHA-256 is published in SHA256SUMS.txt.
